# Getting started

This is a Laravel app generated by AppSeed.

## Local

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
npm install
npm run dev
```

In another terminal:

```bash
php artisan serve
```

Open http://localhost:8000

Default seed user: `admin@example.com` / `password`

## Docker

```bash
docker compose up
```

## Tests

```bash
php artisan test
```

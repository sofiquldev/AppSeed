AppSeed

Pick a stack. Get a folder that boots.

A project composer. Laravel, Next.js, HTML, or WordPress. Features, a UI kit, Docker only where we actually build an image.

Latest release GitHub

Run it

git clone https://github.com/sofiquldev/AppSeed.git
cd AppSeed
npm install
npm run web

Or the CLI

node cli/bin/appseed.js new --stack laravel --name demo --out ./output/demo

What you get

  1. A real stack skeleton, not a translated mock.
  2. Optional auth, users, database, and storage addons.
  3. One Dockerfile per app we build. Official images for Postgres, MySQL, MinIO.
  4. A zip, a local git repo, or a GitHub push.
